# مسار الأصول البصرية النهائية (Pilot V1)

توضع هنا ملفات الأصول Canonical بأسماء `file_name` كما وردت في
`src/data/execution/18_visual_asset_catalog_final.csv`، مثل:

```
VRS-HOME-ITEMS-ORGANIZE-001.webp
```

عند وصول أي ملف، حدّث `missing_binary` إلى `false` للسجل المقابل فقط.
لا تضع هنا نسخًا بديلة (Archive) ولا ملفات نائبة.
