# 10. مبدأ عدم فقد أي عنصر

يجب أن يحصل كل عنصر من الـ1413 على disposition نهائي واحد فقط.

القيم المسموحة:

### A. ACCEPTED
العنصر يمكن تحويله إلى Framework Reference صالح.

### B. MERGED_BY_PROVENANCE
العنصر مكرر دلاليًا، لكنه يحتفظ بعلاقته كمصدر إلى Framework Reference واحد.

### C. SPLIT_REQUIRED
العنصر يحتوي أكثر من Functional Participation ويحتاج تفكيكًا.

### D. EVENT_ONLY
العنصر يمثل Event وليس Functional Participation.

### E. EXECUTION_BLOCK_ONLY
العنصر يمثل جزء تنفيذ وليس Functional Participation.

### F. REWRITE_REQUIRED
الفكرة الوظيفية صالحة لكن التمثيل الحالي غير مطابق للعقد.

### G. EXCLUDED_WITH_REASON
العنصر خارج الحدود المفاهيمية للمشروع الحالي، مع سبب موثق.

لا يسمح بأي حالة:
`UNREVIEWED`
عند إغلاق المشروع.
