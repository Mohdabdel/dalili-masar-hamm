# DALILI — PRODUCTION ACTIVATION TARGET LOCK 01

## القرار التنفيذي

محطة الاستهداف النهائية المعتمدة لمسار العمل الحالي هي:

**تشغيل المواصفة المخططة بكامل طاقتها، متضمنةً جميع الإضافات المعتمدة في المراحل السابقة، حتى بلوغ `PRODUCTION READY`.**

لا يُعد إكمال التصنيف، أو إنشاء مكتبة مرجعية، أو نجاح عينة، أو تشغيل واجهة منفردة محطة نهاية بديلة.

## النطاق الملزم عند الإغلاق

يشمل معيار الإغلاق، دون إسقاط أي مكوّن معتمد:

- معالجة corpus الكامل ذي الـ1413 سجلًا مع حفظ Legacy Master وعدم تعديله.
- Contract Alignment وCanonical Validation وComplexity Validation وException Routing.
- Materialization لكل `GREEN + Canonical PASS` مع هوية ثابتة وprovenance وسجل نسخ.
- بوابة كفاية المكتبة المرجعية ثم Full Discovery Activation.
- المسارات الثلاثة: البداية السهلة، التخطيط الذاتي للمشاركة، واستكشاف المشاركات.
- Family Participation وWorkspace وComposer والتخصيص الأسري.
- Optional Support وPreview وApproval وFrozen Snapshots.
- Learner Card وParticipation Run وOptional Feedback وLifecycle.
- النماذج والإضافات المجمدة السابقة: Functional Participation، Complexity، Provenance، Family Participation، Workspace، Snapshot، Learner Card، Run، Feedback، Lifecycle، والاختبارات المرتبطة بها.
- Full Functional Acceptance وFull Regression وFinal Governance & Data Integrity Audit.

## ما لا يتغير بهذا القرار

- Canonical Validator لا يُخفف ولا يُستبدل ولا يُضاف له bypass.
- Legacy Master يبقى immutable وعدده 1413.
- لا materialization قبل تحقق بواباته الحاكمة.
- المصادر المجتمعية أو التعليمية بوصفها أدلة مستقلة تبقى خارج النطاق الحالي.
- أنظمة التدريب أو التقييم أو mastery أو readiness أو progress tracking تبقى محظورة.

## خط التنفيذ من الحالة الحالية

الحالة المثبتة عند إصدار هذا القفل:

- Phase 2 classification: `1413 / 1413` مكتملة ومعتمدة ومحفوظة.
- unresolved classification records: `0`.
- materialization في مسار الـFull Corpus: لم يبدأ.

→ `Phase 4 Canonical Validation`

## بوابة الإغلاق

لا يعلن اكتمال العمل إلا عند PASS موثق لكل من:

- Architecture Ready.
- Full Corpus Ready.
- Reference Library Ready.
- Family Journey Ready.
- Functional Options Ready.
- Governance Ready.
- Data Integrity Ready.
- Regression Ready.

هذا القفل يثبت محطة الاستهداف ولا يلغي ترتيب البوابات أو شروطها في الخطة الحاكمة.
