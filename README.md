# دليلي Dalele

قم بإنشاء تطبيق ويب للجوال (Mobile-First Web App) مخصص كمنصة تخطيط انتقالي لأصحاب الهمم باسم "دليلي - مسار همم".

التطبيق يجب أن يكون بلغة عربية احترافية ودعم كامل ومطلق للواجهات من اليمين إلى اليسار (RTL Layout)، بتصميم مينيماليست فاخر وأنيق (Corporate Modern Aesthetic) يعتمد على تدرجات ألوان احترافية (الكحلي الداكن #1a365d، الذهبي المطفي الهادئ، والأبيض النظيف).

قم بإنشاء شريط تنقل سفلي تفاعلي (Bottom Navigation Bar) يحتوي على 4 تبويبات أساسية، واحقن في كود التطبيق البيانات الكاملة والتفصيلية لكل جدول من الجداول التالية بدقة شديدة دون اختصار أو إسقاط لأي سطر:
